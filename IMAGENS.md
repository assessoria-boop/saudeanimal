# Imagens · Saúde Animal

Todos os arquivos ficam nesta mesma pasta, sempre em `.webp`.

| Arquivo | Uso | Status |
|---|---|---|
| `logo.webp` | Hero, cabeçalho e favicon | ok |
| `1.webp` a `5.webp` | Carrossel de depoimentos (prints do Google) | ok |

Para trocar ou acrescentar depoimentos, substitua os arquivos numerados.
Se o número de prints mudar, é preciso ajustar os slides e as bolinhas do
carrossel no `index.html`.

## Como converter para WebP
- Online: https://squoosh.app (arraste a imagem, escolha WebP, qualidade 80, baixe)
- Qualidade 75 a 85 já dá ótimo resultado com arquivo pequeno.
